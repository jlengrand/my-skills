# Spinoff Idea

Take an **already-researched** idea, find a gap in the market that would work **much better**, and write it up as a new "spinoff" idea — same documentation as a normal idea, in a separate folder, linked back to the original.

Paths (the vault root is the same for all):
- Researched ideas: `Business Ideas/ideas/`
- Spinoffs: `Business Ideas/ideas_spinoff/`
- Spinoff base: `Business Ideas/Ideas_spinoff.base` (already exists; create it from the template at the end of this file only if missing)

## Step 1 — Choose the original idea

**If the user passed an argument** (e.g. `/spinoff-idea Newsletter aggregator`), match it to a file in `ideas/` and use that as the original.

**Otherwise**, auto-pick the best spinoff candidate:

1. List researched ideas (filled `description`) that are NOT yet spun off. An idea is "already spun off" if any note in `ideas_spinoff/` has `spinoff_of` pointing to it:

```bash
ROOT="/Users/julienlengrand-lambert/Library/Mobile Documents/iCloud~md~obsidian/Documents/Icloud-new-git/Business Ideas"
# already-covered originals (by title). NOTE: macOS ships BSD sed, which does NOT
# support \s — use [[:space:]] and strip the "[[ ]]" wrapper explicitly.
grep -rh '^spinoff_of:' "$ROOT/ideas_spinoff/" 2>/dev/null \
  | sed -E 's/^spinoff_of:[[:space:]]*//; s/^"?\[\[//; s/\]\]"?[[:space:]]*$//' \
  | sort -u > /tmp/spun.txt
# researched ideas, lowest ranking first (most room to improve), skipping covered ones
grep -rl 'description: "[^"]' "$ROOT/ideas/" | while read f; do
  t=$(basename "$f" .md)
  grep -qxF "$t" /tmp/spun.txt && continue
  r=$(grep -m1 '^ranking:' "$f" | sed -E 's/[^0-9]//g'); r=${r:-99}
  printf '%s\t%s\n' "$r" "$t"
done | sort -n | head -10
```

2. From that shortlist, prefer ideas that scored **mid/low (≈3–6)** because the market was **saturated or undifferentiated** — those are where a better angle adds the most value. Read the candidate's note (especially its Research Notes + Competitors) to confirm there's a real wedge to exploit. Pick one.

If there are no eligible ideas, print `NO_SPINOFF_CANDIDATES` and stop.

## Step 2 — Find the gap

Read the original note in full. Then use **WebSearch** / **WebFetch** to find a **repositioning that beats the incumbents**. Look specifically for:

1. **Underserved segment** — a niche, geography, platform, or buyer the incumbents ignore or serve badly.
2. **Wedge feature** — the one capability the original's competitors lack (from the original's own Competitors table — what's the recurring weakness?).
3. **Different business model** — e.g. open-source vs SaaS, one-time vs subscription, local/privacy-first vs cloud, B2B vs B2C, usage-based vs per-seat.
4. **Distribution angle** — a channel or wedge community where this version wins.

The spinoff must be a **concrete, distinct product**, not "the same but better." Name it for what it actually is. Validate it with at least 3 reputable sources (same standard as research-idea): real competitors + URLs, pricing, and demand signals (HN, Reddit, Product Hunt, funding).

Be honest: if the gap doesn't really exist or the spinoff isn't clearly stronger than the original, say so and give it a low ranking — don't invent a winner.

## Step 3 — Write the spinoff note

Create a new file in `Business Ideas/ideas_spinoff/`. Filename = the spinoff's own title (a fresh, descriptive name — not the original's name). Use this frontmatter (same fields as a normal idea, **plus** `spinoff_of`):

```yaml
---
source: ai
spinoff_of: "[[Original Idea Title]]"
ranking: N                 # 1-10, same rubric as research-idea — score the SPINOFF honestly
year: 2026
tags: [tag1, tag2]         # 2-5 short lowercase tags
description: "…"           # 2-3 sentences: what the spinoff is + how it differs from the original
competitors:
  - "Product Name (url)"
pricing: "…"
notes: ""
updated: YYYY-MM-DD        # today's date
---
```

- `source: ai` — these are generated by this skill. Do not use `me` or `neoseed`.
- `spinoff_of` — an Obsidian wikilink to the original note's title (the filename without `.md`), e.g. `"[[Newsletter aggregator]]"`.

### Ranking rubric (same as research-idea)

Market demand · competition (saturated = lower) · feasibility for one developer · differentiation · personal fit (developer tools, AI, productivity, open source). Be critical; most land 4–6. Reserve 8–10 for a genuinely under-served gap with clear demand. The whole point is that the spinoff should usually rank **higher than the original** — if it doesn't, say why.

## Step 4 — Write the note body

Below the frontmatter:

```markdown
> Spinoff of [[Original Idea Title]] — <one line on the gap this exploits>

## The Gap

2-4 sentences: what the original got stuck on (saturation, weak model, ignored segment) and the specific opening this spinoff takes.

## Why this beats [[Original Idea Title]]

3-5 sentences contrasting the spinoff with the original and its incumbents — the wedge, the segment, the model, why it can win where the original couldn't.

## Research Notes

3-5 sentences synthesizing the market, opportunity, and main risk for the spinoff.

## Competitors

| Name | URL | Pricing | Notes |
|---|---|---|---|
| … | … | … | … |

## Sources

- [Page title](url) — one line on what you found there
- …
```

Always include the `spinoff_of` wikilink both in frontmatter AND as the blockquote link at the top, so the link back to the original is clickable in Obsidian and shows in the graph.

## Step 5 — Ensure the base exists

Check that `Business Ideas/Ideas_spinoff.base` exists. If it does not, create it with the template at the bottom of this file. Do not modify it if it already exists.

## Step 6 — Report back

Tell the user:
- The original idea and its ranking
- The spinoff's title, ranking, and the one-sentence gap it exploits
- Why it beats the original
- Any surprising finding from the research

```yaml
filters:
  and:
    - file.inFolder("Business Ideas/ideas_spinoff")
properties:
  file.name:
    displayName: Title
  note.spinoff_of:
    displayName: Spinoff Of
  note.year:
    displayName: Year
  note.notes:
    displayName: Notes
  note.tags:
    displayName: Tags
  note.description:
    displayName: Description
  note.competitors:
    displayName: Competitors
  note.updated:
    displayName: Last Updated
  note.pricing:
    displayName: Pricing Model
  note.ranking:
    displayName: Ranking
  note.source:
    displayName: Source
views:
  - type: table
    name: All Spinoffs
    order:
      - source
      - file.name
      - spinoff_of
      - ranking
      - year
      - tags
      - description
      - pricing
      - notes
      - updated
    sort:
      - property: ranking
        direction: DESC
    columnSize:
      file.name: 421
      note.spinoff_of: 280
      note.description: 480
      note.pricing: 361
  - type: table
    name: By Original Idea
    order:
      - spinoff_of
      - file.name
      - ranking
      - tags
      - description
    sort:
      - property: spinoff_of
        direction: ASC
  - type: table
    name: By Ranking
    order:
      - ranking
      - file.name
      - spinoff_of
      - year
      - tags
      - description
      - pricing
    sort:
      - property: ranking
        direction: DESC
```
